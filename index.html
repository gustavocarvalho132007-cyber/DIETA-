Aparência
Sincronização na nuvem
não configurado — dados salvos só neste aparelho
Como configurar (uma vez, ~10 min)
  1. Crie um projeto em console.firebase.google.com (pode pular o Analytics).
  2. Criação → Realtime Database → Criar banco, em modo bloqueado.
  3. Na aba Regras, cole e publique: 
    {
  "rules": {
    "listas": {
      "$chave": { ".read": true, ".write": true }
    }
  }
}
  4. Copie a URL do topo do banco e cole acima.
  5. Gerar chave → salvar e conectar. No outro aparelho: mesma URL, mesma chave.

A chave (24 caracteres aleatórios) funciona como senha: só sincroniza quem a tiver.
